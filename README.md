# Версия 3
- Нельзя сохранить пустую операцию: для дохода/расхода обязательны дата и сумма.
- Если есть только доход, расходные поля сохраняются как `-`; если только расход — доходные как `-`.
- Удалена временная отметка `updatedAt`; при запуске новой версии старый столбец автоматически удаляется.
- Настройки синхронизации скрыты за кнопкой ⚙ слева и сохраняются после обновления.
- Цвета: доход — светло-зелёный, расход — светло-красный.

После замены `Code.gs` обновите развёртывание: **Развернуть → Управление развёртываниями → редактировать → Новая версия → Развернуть**. URL `/exec` можно оставить тем же. На GitHub замените `index.html`, `style.css`, `app.js`.


### Версия 4
- После успешного «Сохранить» повторное сохранение заблокировано на 10 секунд.
- В «Синхронизация» добавлено поле кодового слова `Raitvok`.
- Код требуется для «Изм.», «Удалить» и «Очистить таблицу».
- Проверка кода выполняется также на стороне Apps Script.
- Даты показываются только в формате `ДД.ММ.ГГГГ`, без времени и `Москва`.
- После замены `Code.gs` обновите развёртывание Web App через «Управление развёртываниями» → ✏️ → «Новая версия» → «Развернуть».
