# Версия 2

Изменения:
- URL и ключ сохраняются в браузере и автоматически восстанавливаются после обновления.
- Поля доходов — светло-зелёные.
- Поля расходов — светло-красные.
- В таблице сайта доходы и расходы разделены цветом.
- Google Таблица автоматически форматируется: доходы зелёным, расходы красным, заголовок закреплён.

После замены Code.gs в Apps Script нужно обновить развёртывание: **Развернуть → Управление развёртываниями → редактировать → Новая версия → Развернуть**.
