# Расходы и доходы — веб-версия

Статическое веб-приложение для GitHub Pages.

## Функции
- доход: дата и сумма;
- расход: дата, сумма и получатель;
- автоматическая разница по каждой строке;
- общий доход, расход и остаток;
- редактирование и удаление;
- локальное сохранение через localStorage;
- календарь браузера;
- отчёт за период;
- печать / сохранение отчёта в PDF;
- адаптивный интерфейс для телефона и компьютера.

## Запуск
Откройте `index.html` напрямую или:
`python -m http.server 8080`

## GitHub Pages
Загрузите файлы в репозиторий → Settings → Pages → Deploy from branch → `main` → `/ (root)`.

Данные не передаются на сервер. Они хранятся только в браузере конкретного устройства.
