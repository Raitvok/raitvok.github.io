# Версия с Google Таблицами

1. Создайте Google Таблицу.
2. Откройте **Расширения → Apps Script**.
3. Вставьте код из `Code.gs`.
4. В `Code.gs` замените `ВСТАВЬТЕ_ID_ТАБЛИЦЫ` на ID таблицы и задайте свой длинный `APP_KEY`.
5. Запустите `setup` один раз и выдайте разрешения.
6. **Развернуть → Новое развёртывание → Веб-приложение**.
7. Выполнять от имени: **Меня**. Доступ: **Все**.
8. Скопируйте URL `/exec`.
9. Загрузите `index.html`, `style.css`, `app.js` на GitHub Pages.
10. Откройте сайт и вставьте URL Web App и тот же ключ.

После этого операции сохраняются в Google Таблице и доступны с телефона и компьютера.

Важно: это личная простая схема. Ключ находится в браузере, поэтому для банковских/чувствительных данных нужна полноценная авторизация.
